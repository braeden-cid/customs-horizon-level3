# Customs Horizon — Level 3

Built output only. Two pages, one room.

- **`/`** — the level. Nine steps, from sitting down to naming a cause.
- **`/sandbox/`** — the same room with every part unlocked at once. No steps, no
  progression, nothing to finish. Press Reset (or hold **A** in a headset) to put
  it back.

**In a headset:** open either page in the browser and press **Enter VR**.

**At a desk:** `W A S D` to move, mouse to look (press **Look** first), `F` to
stand or sit, `R` to return to the seat. Click to pick things up.
